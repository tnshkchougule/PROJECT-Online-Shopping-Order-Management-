# PROJECT-Online-Shopping-Order-Management-
A simple Online Shopping Order Management System developed in C using structures and arrays to manage customer orders, calculate total prices and discounts, update order status, identify delayed orders, and calculate revenue from delivered orders.
# Online Shopping Order Management System

## About the Project
The Online Shopping Order Management System is a mini project developed using the C programming language. It helps manage customer orders in an online shopping system.

The project uses **structures and arrays** to store and manage order details, including order ID, customer name, product name, quantity, unit price, order status, and order date.

## Features
- Add and store customer orders.
- Calculate the total price of an order.
- Apply a 10% discount when the total amount exceeds ₹5,000.
- Update order status from Pending to Shipped and Delivered.
- Identify delayed pending orders that are older than 3 days.
- Display order details.
- Calculate total revenue from delivered orders.

## Technologies Used
- Programming Language: C
- Concepts: Structures, Arrays, Functions, Loops, and Conditional Statements.

## How to Run
1. Download or clone this repository.
2. Open the project in a C compiler, such as GCC or VS Code.
3. Compile the C program.
4. Run the executable and follow the menu options.

### Compile and Run
```bash
gcc main.c -o order_management
./order_management
```

On Windows, run:
```bash
order_management.exe
```
